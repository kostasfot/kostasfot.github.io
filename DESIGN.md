# Public Observatory

Native Jekyll + plain browser JavaScript. The existing site layout, navigation,
fonts and dark colour system own the presentation. Plotly.js 4.0.0 is vendored
unchanged from the analytics project's locked Plotly 7.0.0 runtime; license
notices are retained. No server, database service, login or paid hosting exists.

`assets/js/observatory.mjs` renders precomputed chart specs and exact tables from
one versioned `assets/data/observatory/<release>/snapshot.json`. It performs
filtering and display formatting, not KPI calculations. Local browser CSVs retain
all filtered fields and protect formula-like text. The full CSV/ZIP release is
generated by the analytics repository, never assembled manually in this site.

The dashboard and article use the same release. Ten default dashboard charts and
eleven article figures account for the cleared analytical evidence. The article
shows both source-market measures; other repeated source visuals are deduplicated.
Unsupported market years and missing comparisons are visible gaps, not zeros.

Source rights, population breaks and coverage are explicit. The initial public
edition is ELSTAT/Eurostat accommodation, 2019–2024 plus separately labelled 2025
capacity. Bank of Greece-derived data, Fraport traffic and GISCO geometry are
withheld pending appropriate publication clearance. Their old affected article
images/data are removed from the currently served tree without rewriting history.

Test entry point: `node --test tests/observatory.test.mjs`. Build with the existing
`bundle exec jekyll build --trace`. Browser QA covers desktop/phone layout,
destination and market selectors, URL filters, missing years and download flows.
Future snapshots require manual source review and coordinated article updates.

## Release acceptance — September 11, 2026

Release `2026-09-11-v1` was exported from analytics commit
`34a19772c8c98a944ecb9d7880b87423b8ab5ec6`, with fresh ELSTAT/Eurostat
input provenance. Exact release bytes are protected from Git newline conversion
by `.gitattributes`. Prior preview-only data is not published.

Jekyll production build and the website's manifest, article-value, filter and CSV
tests passed. All ten dashboard plots and eleven article plots were inspected;
phone checks included navigation, long regional labels and exact tables. Tested
Thessaloniki, Greece markets, the unsupported 2019 national market denominator,
return to the default region/year, and initial deep-link positioning. No browser
JavaScript errors were observed. Full ZIP download succeeded. The in-app browser
did not save generated CSV downloads; their direct-link encoded contents were
verified against selected rows. Full individual CSV/ZIP URLs remain available
as the browser-independent fallback; a generated-download save in an external
browser was not tested.
